### 一、认识计算广告
计算广告=计算＋广告
计算广告≠互联网广告≠程序化广告
研究目标是实现语境、广告、受众的三者的最佳匹配
信息科学 统计学 计算机科学 微观经济学交叉学科

#### 1. 计算什么
如果用传播学中的 5W 来解释广告的可计算性，那么每一个“W”都是可以被计算的。

| 5W | 含义 | 可计算的内容 |
| --- | --- | --- |
| Who | 广告的基础 | 品牌 / 定位 / 市场 / 竞争 / 产品·服务 |
| Says What | 广告的内容 | 策划 / 创意 / 文案 / 表现 / 价值取向 |
| In Which Channel | 广告的发布 | 时间 / 频次 / 形式 / 组合 / 费用 |
| To Whom | 广告的对象 | 用户画像 / 用户认知 / 用户心理 / 用户行为 / 用户态度 |
| With What Effect | 广告的效果 | 品牌形象 / 销售转化 / 营销配合 / 行业竞争 / 用户反馈 |

**补充说明**
现代广告本身是一种科学与艺术相结合的产物。其科学性有赖于数据的使用。
在新媒体环境中，大数据和人工智能进一步提升了广告活动的科学性。

#### 2. 谁来计算
如果从广告活动的参与者来看广告的可计算性，那么每一个要素都可以是计算的主体。

| 角色 | 定位/职责 | 可计算的内容 |
| --- | --- | --- |
| 广告主 | 广告发起者 | - 拥有基础数据<br>- 判断广告效果<br>- 维系客户关系<br>- 掌握广告决策 |
| 广告代理商 | 广告承揽者 | - 主导广告活动<br>- 关注广告效果<br>- 维系广告关系<br>- 提供广告方案 |
| 广告媒体 | 广告发布者 | - 承载广告活动<br>- 拥有直接数据<br>- 提供广告效果<br>- 创建广告环境 |
| 广告目标受众 | 广告接收者 | - 参与广告互动<br>- 贡献广告数据<br>- 影响广告效果<br>- 决定品牌价值 |

**补充说明**
广告产业链条中的各个环节各司其职，共同促进产业的整体发展。
每个环节的参与者都可以根据自身的能力和优势，搜集数据与信息，成为广告中的“计算”。

### 三、计算广告基本形态与业态
• 计算广告要实现的是通过广告算法对广告、语境/场景、受众/用户三个要素进行匹配。
• 在这个目的之下，逐渐形成了计算广告的基本运作模式。
• 基于这个目的和模式，不同的参与机构会结合自身资源形成独特的广告业务体系，进而形成不同的计算广告形态与业态。

### 五、数字化改变广告主
伴随着信息技术的发展，广告产业发生颠覆性变化，进入计算广告时代。数字化也在全方位改变着广告主，广告主的营销策略也在发生根本性改变。

数字化带来的主要改变：
◦ 改变营销目标
◦ 改变与消费者的关系
◦ 改变与媒体/广告公司的关系
◦ 改变组织架构与业务流程

广告主积极投入数字营销。近年来，企业在数字营销方面的投入以约年20%左右的速度增长。2022年超过80%的广告主表示会继续增加数字营销方面的投入。短视频和KOL（关键意见领袖）成为数字营销投入重点。内容标签化和数据中台目前应用最为广泛的营销新技术。

**-- 消费者与消费行为**
**1.消费者的概念**
消费者定义与行为影响因素
• 消费者是在消费过程的不同阶段中产生需求或欲望、实施购买并处置产品的人。
• 广义上的消费者是指所有从事物质产品和精神产品消费活动的人，是一个庞大的社会群体。
• 狭义上的消费者是从市场需求的角度界定的。不同的企业和产品，其消费者也会存在不同。
• 消费者的消费心理与消费行为，会受到内外部多种因素的影响。

**数字化时代相关研究与新术语**
伴随着数字化时代的到来，关于消费者的相关研究也在不断丰富。以下是列出的新术语及其代表性文献：
• 数字化消费者行为 (Digital Consumer Behavior): Solomon (2009)

• 数字化传播 (Digital Communication) / 数字化口碑 (eWOM): Kotler和Keller (2015)
• 数字化生活方式 (Digital Lifestyle): Charmonman和Chorpothong (2005)
• 数字原住民 (Digital Native): Prensky (2001)

**2.消费者行为**
自20世纪80年代以来，西方学术界围绕消费者行为定义展开了较长时间的争议，迄今为止没有一个完全统一的定义。
• 决策过程论将消费者行为定义为消费者购买、消费和处置的决策过程。（yes!!）
• 体验论认为消费者行为是消费者的体验过程，是一种偏感性的行为——消费者在体验中购买，在体验中消费，在体验中处置。
• 刺激-反应论认为消费者行为是消费者对刺激的反应。
• 平衡协调论认为消费者行为是消费者与营销者之间的交换互动行为，是双方均衡的结果。
• 美国市场营销协会的定义： 消费者行为是感知、认知、行为以及环境因素的动态互动过程，是人类履行生活中交易职能的行为基础。其本质是消费者心理、行为与外部环境交互作用的结果。

**消费者行为研究！**
消费者行为与市场营销：市场营销的一切活动都是围绕消费者进行的，对消费者心理及购买行为具有直接影响，两者相互影响、相互作用。广告是其中最典型的部分。
消费者心理与社会环境：一方面，消费者的心理及行为在很大程度上受到社会环境因素的影响和制约；另一方面，消费者在适应环境的同时也会以不同方式影响和反作用于环境。
消费者的心理活动基础： 包括感知、记忆和学习、个性心理、态度的形成与改变、消费需求和动机、消费者满意与忠诚等。把握心理活动规律为消费者行为的研究奠定基础。
消费者的购买决策与行为： 消费者行为是消费心理活动的集中体现，是消费活动中最有意义的部分，在消费的前、中、后环节均有体现。
消费者群体心理与行为： 消费在直接形态上表现为消费者个人的行为活动，但从社会总体角度看，消费者行为带有明显的群体性。

• 消费者研究是在对市场环境（政治、法律、社会、文化、技术）、人口特征、生活方式、经济水平（了解平均收入）等基本特征进行研究的基础上，运用各种市场调研技术和方法，对消费群体通过认知、态度、动机、选择、决策、购买、使用等阶段实现自身愿望和需要的研究。
• 消费者研究的目的是为企业的营销与广告活动提供相应的指导。

**-- 小结**
在我们的课程学习中，用户和消费者是最常出现的概念，也是可以互相通用的概念。当用户在使用媒体产品时，其实也是这个产品的消费者。那么，在对他们进行研究时，我们的研究核心是什么？
1. TA的基本信息 (Demographics)（这里的TA不是他！！是目标受众)
一般来说，我们会对用户的年龄、性别、收入、职业、受教育程度等数据进行收集，并且按照这个方式对Ta进行归类。这些信息描述的是一个群体特征的部分因素，也称为人口统计变量 (demographics)。
◦ 性别、年龄、活跃程度、品牌偏好、购买力、学历、教育程度、购物偏好、地域。
2. TA的心理特征 (Psychographics)
在我们了解了用户的人口统计信息之后，还会想要了解用户的一些偏好，比如穿着打扮、休闲方式、娱乐选择、就餐口味、价值观、性格特征等等。这类反映偏好和价值观的信息，我们称之为心理地图变量 (psychographics)，描述的是一个人生活方式和个性方面的情况。
3. TA的行为特征
我们还想要知道，作为使用者和消费者，其消费及使用的前中后不同阶段，都会有哪些特点，比如是否会去搜索相关信息，是否会受到广告的影响，是否会接受他人的安利，是否会在社交媒体上分享使用体验等等。
4. 以上因素如何发生相互作用、相互影响
一个人的行为是由其思想和心理来决定的，行为的产生应首先受心理意识的影响，而个人行为又会反过来对其心理产生一定的影响，改变心理意识。所以心理与意识是相互影响，相互转化的。在具体的场景中，这种相互作用发生的契机、程度、表现等都会有差异，也就成为了我们研究的一个视角。

新媒体环境使得每个人都在网络上留下活动痕迹，这些痕迹蕴含了大量的信息，成为营销与广告活动的重要支撑。计算广告的“计算”目标之一，就是在科学的指导之下充分利用这些信息，提升广告的精准性和有效性。

### 01 如何理解计算广告的投放？
**-- 投放与用户洞察、创意的关系**
计算广告时代，媒介投放的基本逻辑没有改变
• 广告投放的本质一直都是用户、广告主和媒体平台三方利益的动态平衡。
• 用户通过媒体平台获取信息，媒体平台根据其兴趣意图向用户推荐相关端的广告。
• 媒体平台的目标是整体经济收益，广告主的目标是获得投入效益最大化。
• 不论投放形式和过程如何变化，媒介投放这一底层逻辑和任务并没有改变。

**--数据和技术深刻改变了广告投放的演进**
关键点：
• 计算广告投放依赖于两个重要事情：
a. 准确、海量的目标受众数据。
b. 强大的自动化算法，以保证合理竞价。
人工智能算法技术在广告投放的应用示例：监督学习 / 无监督学习。

实际的计算广告投放：

2、价格机制：计算广告投放的交易模式，按照什么价格来交易？底价与二价竞价
底价 (Reserve Price)：媒体会为每个广告位设置底价，保证媒体的最低收入。
二价竞价 (Second Price Auction)：作为竞价胜出者的广告主所支付的广告费是根据排第二的广告主出价溢出计算的。
为什么会采用二价？采用二价竞价，扣费价格是按排第二的广告主出价计算的，这一定会低于广告主自己的出价，广告主没有理由调降自己的出价，这是一种“魔幻的麻醉心理”。

PDB 广告投放操作流程：
商务洽谈 -> 广告排期下单 -> 生成 Deal 订单 -> 资质提交与审核 -> 素材提交与审核 -> 提供打底素材和落地页 -> PDB 活动设置 -> 正式投放
“推送” 即为媒体可以提供给客户的流量，“优选” 即为经过判断选中的流量。
返还率 = (推送 - 优选) / 推送

“包剧”投放：是各个视频平台推的计算广告投放模式，媒体资源多为头部资源；广告主多为快消行业。
