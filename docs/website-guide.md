# BadTowel 网站介绍

> 毛巾坏 / badtowel 的个人创作网站
> "拥抱千万个的你，呓语终究是一隅。"

---

## 一、网站概览

BadTowel 是一个集**诗歌、音乐、博客、笔记**于一体的个人创作网站，内置 AI 助手"小毛巾"，提供智能对话、作品推荐、深度解读和语音朗读等功能。

**技术栈**：Astro + Tailwind CSS + Decap CMS + Fuse.js + 小米 MiMo API

**设计风格**：玻璃态（Glassmorphism）+ 毛玻璃背景 + 深蓝主色调（#00395A）

### 2. 诗歌页面（/poetry）

左栏为诗歌列表，右栏为阅读区域。支持按**诗集**筛选（标签按钮）。

**诗集分类**：
- 春疯
- 将晓
- 以及其他独立诗作

**功能亮点**：
- **诗集筛选**：顶部标签栏点击切换不同诗集
- **小标题**：诗中以 `# ` 开头的行渲染为带左侧渐变竖线装饰的小标题
- **段落呼吸间距**：空行分隔的段落之间有更大间距，形成阅读节奏
- **创作背记**：部分诗歌附带创作背景，点击弹出可拖动浮窗
- **上下首导航**：底部"上一首/下一首"按钮快速切换
- **星标作品**：标记为偏爱的诗歌显示金色星标
- **未公开标记**：未公开的诗歌显示锁图标，非管理员无法查看

### 4. 博客页面（/blog）

- **表格**：支持完整的表格渲染
- **引用**：左侧蓝色竖线的引用样式

### 7. AI 助手页面（/assistant）— 小毛巾

左右分栏布局的 AI 聊天界面。

**左侧边栏**：
- 品牌标识"小毛巾"
- 网站诗句引言
- 新对话/历史/深度思考按钮
- 功能介绍卡片
- 底部信息

**右侧聊天区**：
- 欢迎页面 + 6 个快捷操作卡片
- 流式对话（逐字显示）
- Markdown 渲染（加粗、斜体、标题、列表等）
- 多轮对话 + 历史记录管理

**核心功能**：

| 功能 | 说明 |
|------|------|
| 🎯 推荐作品 | 根据心情和兴趣推荐诗歌/音乐/博客/笔记 |
| 🔍 深度解读 | 对作品进行赏析和解读 |
| ✨ 创作灵感 | 基于网站内容激发灵感 |
| 💬 聊天陪伴 | 用中文自然对话 |
| 🧠 深度思考 | 切换 mimo-v2.5-pro 模型进行深度推理 |
| 🔊 声声入耳 | TTS 语音合成，4 种音色 + 自定义风格 |

**声声入耳（TTS）**：
- 触发方式：在对话中说"读读xxx"或"读读这个"
- 智能识别：说"读读这个"时，调用独立 API 从上下文中提取要朗读的诗句/歌词
- 音色选择：冰糖（女声）、茉莉（女声）、苏打（男声）、白桦（男声）
- 风格控制：支持自然语言描述（如"深情低语"、"东北话"、"活泼俏皮"）
- 音频消息：生成后显示播放按钮气泡，点击播放/暂停
- 再生成：说"再生成一遍"重新打开朗读卡片

**快捷操作栏**：
输入框上方提供 5 个快捷按钮：推荐作品、创作灵感、读读这个、再生成、了解网站。

**频率限制**：
- 每小时最多 50 次交互
- 每天最多 100 次交互
- 超限时小毛巾会提示等待时间

## 三、全局交互功能

### 文字选择工具栏

在诗歌、歌词、博客、笔记的文章区域选中文字后，弹出浮动工具栏，包含三个操作：

1. **划线** — 青绿色高亮标记选中文字
   - 防重复划线（已划线的文字无法重复划线）
   - 新范围覆盖旧范围时自动替换
   - 重叠时提示"请先取消再划线"
   
2. **问问小毛巾** — 跳转 AI 助手解读选中文字

3. **声声入耳** — 跳转 AI 助手朗读选中文字

### 划线后点击弹窗

点击已划线的文字，弹出操作菜单：
- 复制 — 一键复制文字
- 问问小毛巾 — 跳转 AI 助手解读
- 声声入耳 — 跳转 AI 助手朗读面板
- 取消划线 — 移除高亮

### 导航栏

- **搜索框**：输入文字搜索网站内容（Fuse.js 模糊搜索），按回车跳转小毛巾对话
- **小毛巾按钮**：快速进入 AI 助手页面
- **各页面链接**：首页、诗歌、音乐、博客、笔记、关于

### 回到顶部

阅读内容滚动超过 300px 后，右下角自动出现回到顶部按钮。

## 五、配置与定制

### 全局配置（src/config.ts）

| 配置项 | 说明 |
|--------|------|
| `heroSentences` | 首页打字机轮播句子 |
| `heroImage` | 首页背景图路径 |
| `mascotImage` | 吉祥物图片路径 |
| `about` | 关于页内容（问候语、正文、署名） |
| `socialLinks` | 社交平台链接 |

### AI 配置（src/ai-config.ts）

| 配置项 | 说明 |
|--------|------|
| `apiKey` | MiMo API Key |
| `apiEndpoint` | API 端点 |
| `model` | 快速对话模型（mimo-v2-flash） |
| `deepModel` | 深度思考模型（mimo-v2.5-pro） |
| `systemPrompt` | 系统提示词（AI 的性格和能力定义） |

### 主题色（src/styles/global.css）

```css
:root {
    --color-accent: #00395A;       /* 主色（深蓝） */
    --color-accent-light: #144767;  /* 主色浅 */
}
```

## 六、部署

推荐使用 **Vercel** 部署：

1. 将代码推送到 GitHub
2. 在 vercel.com 导入项目
3. 框架自动识别为 Astro，直接部署
4. 每次 push 到 main 分支自动重新部署

开发环境 API 通过 Vite 代理（`/api/mimo` → `api.xiaomimimo.com`），部署后需配置生产环境代理或使用 Serverless Function。
